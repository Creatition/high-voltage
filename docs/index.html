Timeshot

A time-travel bullet-hell roguelike. Windows, early build.

Download for Windows
~35 MB ZIP · unzip and run Timeshot.exe

First-time setup

  1. Download and unzip anywhere.
  2. Run Timeshot.exe.
  3. Windows SmartScreen may warn that the app is unrecognized — click More info then Run anyway. The build isn't code-signed yet.

Controls

  • WASD — move
  • Mouse — aim
  • Left click — shoot
  • Space — dodge
  • Esc — pause

Feedback

This is an early build. Bugs, weirdness, and missing features are expected. If something breaks or feels wrong, let me know.
